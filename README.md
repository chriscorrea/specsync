# specsync

CLI for syncing local markdown files. 
Write docs alongside your code, then push them somewhere your whole team can read and collaborate.

## Installation

```bash
make build
./specsync init
```

Run `make help` to see all available build, test, and development commands.


## Getting Started

```bash
specsync init              # create .specsync.yaml config

specsync push              # push files (not yet implemented)
```
